新增网易 UU 自动加速 VRChat，并重新设计设置界面。

- 支持在 SteamVR、VRChat 或任一程序启动时触发，UU 未运行时可自动打开。
- 支持选择具体区服，以及游戏退出后停止本工具启动的加速；保留用户原有加速。
- 增加 UU 授权引导和只读连接检查，连接状态与实际加速状态分别显示。
- 修复下拉框失焦后文字消失、点击时页面跳动，以及加速超时后的旧请求阻塞重试。
- 修复跳过壁纸操作被记为成功暂停、源码运行时自启命令引号，以及升级覆盖配置的问题。
- 新安装默认每 1 秒检测 SteamVR / VRChat；升级保留已有设置。

下载 `SteamVRWallpaperPause-Setup.exe` 安装或升级，也提供独立程序和 `SHA256SUMS.txt`。
UU 功能默认关闭；使用前需在官方 UU 客户端的 AI 设置中手动开启授权，
再到本工具中检查连接、启用自动加速并保存具体区服。

验证：65 项自动测试通过；Windows 构建验证独立程序入口、首次安装的 1 秒默认值、
安装包内程序一致性及升级时完整保留已有配置。
